## Инварианты лабораторной работы

1. **Класс `BankAccount`:**
   - Начальный баланс и остаток на счете (`balance`) никогда не могут быть отрицательными (`balance >= 0`).
   - Суммы для пополнения (`deposit`) и списания (`withdraw`) должны быть строго положительными (`amount > 0`).
   - Невозможно списать сумму, превышающую текущий баланс (`amount <= balance`).

2. **Класс `DataSample` (Инженерия систем искусственного интеллекта):**
   - Уникальный идентификатор (`id`) и метка класса (`label`) обязательны: они не равны `null` и не являются пустыми строками или строками из одних пробелов.
   - Массив признаков (`features`) не должен быть `null` и не должен быть пустым (`length > 0`).
   - Защитное копирование: массив признаков копируется в конструкторе и при возврате из геттера (`getFeatures()`), исключая неконтролируемое изменение извне.
   - Статус наблюдения (`status`) может изменяться только через метод `changeStatus()`.
